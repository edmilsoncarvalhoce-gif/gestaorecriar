# Recriar Gestão

Protótipo demonstrativo de gestão para clínica multidisciplinar, com agenda,
controle de salas, pacientes, atendimentos, financeiro, profissionais e
configurações.

Todos os nomes, valores e registros exibidos são fictícios.

## Executar

```bash
npm install
npm run dev
```

## Produção

```bash
npm run build
npm start
```
